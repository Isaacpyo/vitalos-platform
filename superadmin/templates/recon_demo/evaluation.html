    How to run it

    Offline (no key, no network; the CI gate runs the first command):

    cd superadmin
python manage.py recon_eval --dataset v1 --config rules-only --config rules+simulated-model --out /tmp/eval
python manage.py recon_eval --dataset v1 --config rules-only --config rules+simulated-model \
  --compare rules-only,rules+simulated-model --out ../docs/ai-data/evaluation/v1 --out apps/recon_demo/reports/v1

    Live (AC-14; needs AI_DATA_LLM_API_KEY, never in CI; the AI & Data live evaluation workflow runs it from main with a hard cap):

    python manage.py recon_eval --dataset v1 --config rules+live-model --max-calls 40 --out /tmp/live-eval
