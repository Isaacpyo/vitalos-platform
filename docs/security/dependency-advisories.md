# Dependency advisories

`pnpm check:security` (CI, `quality` job) runs the tracked-file secret scan and `pnpm audit --audit-level high`. The level is not lowered. Fixes are exact-version, narrowly scoped `overrides` in `pnpm-workspace.yaml`; the only exception is an advisory-specific `auditConfig.ignoreGhsas` entry. Re-run `pnpm audit --audit-level high` when reviewing and drop an override once the parent package ships the fix itself.

Baseline recorded 2026-10-10: 13 high and 2 critical, counted as pnpm counts them (one per advisory and affected version range, so brace-expansion is 4 and adm-zip is 4; the table groups them by package). 15 in total. After this change: 0 critical, 0 high unignored, 1 high ignored (braces).
