# Keyword map

Every indexable URL has one primary topic, two to four secondary phrases, an intent and its internal links. **Each phrase has exactly one owner page**: another page may mention the phrase in its copy, but it never targets it in its title, h1 or description. Spelling is UK English.

**Volumes and difficulty: to validate.** None of the connected tools gives keyword data yet. Search Console and Bing Webmaster Tools need the owner's sign-in (LAUNCH.md §3), and Keyword Planner needs a Google Ads account. No figure is estimated. When real data arrives, add `vol` and `kd` columns with the source and date, and move a phrase to another page only by editing this file.

Intent: **C** = commercial investigation, **T** = transactional (a bounded way to start), **S** = sector-qualified commercial, **N** = navigational or brand, **I** = informational.

"Title" is the `<title>` this branch sets (≤ 60 characters, topic first, brand last). The visible h1 does not change unless noted.

## Cannibalisation checks

| Pair                                                                | How it is resolved                                                                                                                                                                                                  |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Solution and offer both named "Application Modernisation"           | The solution owns "application modernisation" and "legacy application modernisation" (C). The offer owns the engagement: "refactor or replace legacy software" (T). The titles differ; the offer's h1 is unchanged. |
| Home and Consulting both about "technology consulting"              | Home owns the category ("consulting, engineering and digital transformation company"). Consulting owns "technology strategy consulting".                                                                            |
| Engineering and Custom Digital Product both about building software | Engineering owns "software engineering services". The offer owns "custom digital product development" and "custom software development".                                                                            |
| Managed Services and Application Care                               | The practice owns "managed application and platform services". The offer owns "application maintenance and support".                                                                                                |
| AI & Data, AI Transformation and AI Opportunity Assessment          | The practice owns "AI consultancy". The solution owns "AI transformation". The offer owns "AI readiness assessment".                                                                                                |
| Data & Intelligence (solution) and Data & BI (offer)                | The solution owns "data and intelligence transformation" and data governance. The offer owns "BI modernisation" and reporting.                                                                                      |
| Product Discovery and Digital Transformation Discovery              | The offer named after the product owns "product discovery". The other owns "digital transformation discovery" and the transformation roadmap.                                                                       |
| `/faq` and the solution pages' "Common questions"                   | The solution pages own their questions; `/faq` collects them for navigation and carries no FAQPage markup (DECISIONS 8).                                                                                            |
