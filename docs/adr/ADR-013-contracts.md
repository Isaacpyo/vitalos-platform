# ADR 013 API and event contracts

Status: Accepted future standard.

Context: Extraction needs stable boundaries. Decision: version meaningful APIs/events, use OpenAPI/JSON Schema/AsyncAPI, compatible change and idempotency. Options: shared implementation types or informal payloads. Reasons: independent evolution. Trade-offs: schema lifecycle overhead. Consequences: no public API/event bus yet. Revisit triggers: second consumer or external boundary.
