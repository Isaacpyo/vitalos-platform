# ADR 008 Figma and code token workflow

Status: Accepted.

Context: Approved Stage 9 visuals must not drift. Decision: Figma owns approved design, source tokens implement it, Storybook verifies components. Options: ad-hoc CSS or generated screenshots. Reasons: auditable reusable design. Trade-offs: explicit synchronization work. Consequences: token changes require design review. Revisit triggers: automated token pipeline becomes reliable and owned.
