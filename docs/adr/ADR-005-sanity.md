# ADR 005 Sanity editorial platform

Status: Accepted; remote project unconfigured.

Context: Editors need structured relational content and preview. Decision: isolated Studio and shared governed schemas. Options: code-only MDX, page builder, custom admin. Reasons: editorial independence and typed structure. Trade-offs: provider dependency and schema governance. Consequences: no arbitrary HTML/CSS; operational data stays elsewhere. Revisit triggers: workflow, residency or cost no longer fits.
