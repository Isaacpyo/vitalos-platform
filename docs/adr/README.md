# Architecture decisions

ADRs are immutable decision records. Supersede rather than rewrite accepted history. Every ADR includes status, context, decision, options, reasons, trade-offs, consequences and revisit triggers. Later facts that contradict an ADR are added as a dated "Status update" at its end; the original decision text is not edited.
