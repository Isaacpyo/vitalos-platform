# Engagement model

## Two ways in

- Consulting first: discovery, assessment and architecture, then engineering.
- Engineering direct: when requirements are already clear enough to build.
- Complex, uncertain or high-risk projects start with discovery. Say so on the website, in proposals and in sales conversations.

## The full journey

Understand the problem, define the opportunity, architect the solution, engineer the system, deploy it, operate and improve it. Show this as one path with `cobalt` strategy and `mineral` engineering converging (see `GraphicMotif`).
